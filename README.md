<h1>Diivavälitys</h1>
<h3>A website for a drag talent agency</h3>

Tech stack:
* Next.js
* TypeScript
* React
* Tailwind CSS
* Headless CMS Sanity

Next.js, TypeScript, React and Tailwind were the core tech stack I used in our final project at Hive Helsinki. I wanted to strengthen these skills in a real-world project.

For content management I chose Sanity, because the volume of the website content is fairly small, and Sanity offers a nice and intuitive UI that's easy to use - no code needed, so the client can easily add and edit the contents of the site on their own.

The website features a gallery of the agency's artists, an events listing, a contact form and a blog-type section for sharing news - and a Diva Name Generator!
